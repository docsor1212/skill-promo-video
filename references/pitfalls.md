# 错误全录（P0 流程 / P1 内容 / P2 技术）——skill-promo-video

> 每条都是真实返工换来的。制作前通读；踩新坑回来追加。

## P0 流程性（重复翻车型，违反=整段重来）

1. **版式合成早于底图定稿** → 旧图混入成片（历史上发生过两次）。铁律：版式合成是合成的紧前步骤，全部底图定稿后才跑。
2. **TTS 批量假 OK**：GPU 被生图队列占满 → 引擎全量 OOM 但循环 rc=0、旧 wav 未覆盖 → 旧旁白混入成片（交付闸门才抓到）。铁律：逐个验 wav 存在+mtime 新鲜+size（tts_batch.py 已内置），任一失败=整批不可信。
3. **生成段自动音轨混入**：成片出现无意义 AI 音频。铁律：生成段一律 `-an` 重封装，成片 ffprobe 验证单视频流+明确音轨表。
4. **多脚本 sed/replace 补丁链静默失效**（文件名/路径替换不生效 → 合成跑错版本两轮不自知）。铁律：脚本一次成型 Write，执行前 grep 关键行；输出/中间产物用唯一名。
5. **旁白超所在段时长** → 尾音盖下一段开头。铁律：文案压短或扩段时长；narr 窗口逐条核对。
6. **闸门最后跑**：任何素材变更后，此前所有闸门结果作废，必须全量重跑。

## P1 内容质量（用户否决型）

7. PIL 贴字封面被否（贴补感）→ 全部文字 PE 直出。
8. 瞎编词/生造词 → 用词朴素准确，宁短勿花。
9. 提示词卡只写标题没写全文 → 必须一字不多不少的真实提示词原文。
10. 数据专业不符 → 按目标用户领域选数据。
11. 简笔示意图粗糙 → 不放（真实图在图页完整呈现；缩略图会遮文字）。
12. 片尾字体太小（手机观看）→ 关键文字横跨 ≥75% 画面宽。
13. 水印三连否（斜纹单调/纯文字无记忆点/花哨渐变）→ signature 图腾方法论（见 pipeline.md Step 10）。
14. 内部视角措辞（「已上架」类）→ 用户视角表述；评测与榜单分行。
15. 道具画错 → 道具从简，选已验证形态。
16. 人物手部多指/并指 = **一票否决** → 交付前放大双手逐指清点（qc_gates.py hands 出裁片供复核）。

## P2 技术细节

17. TTS 文本含「？」静默失败（rc=0 无输出）→ 批量前统一替换为句号。
18. 单卡 24G 多模型互斥：TE 常驻 ~16G 与生图/H3 不可共存 → kill→free→load 串行纪律。
19. ASS Events Format 必须全 10 字段（6 字段会把 MarginL 坐标吃进文本）。
20. 字幕结束=本段尾（溢出到下一页同屏=穿帮）。
21. xfade 各输入必须统一 fps/scale/pad 后再链。
22. 火山图天花板效应：p 值全顶格 → 点粘顶；构造式梯度数据才出三带形态。
23. matplotlib sharey 组内 tick_params 传播（面板图改字体会串轴）。
24. scp/远端写文件时序竞态（0 字节）→ 拉回后验 size。
25. 远程/管道传输内嵌复杂内容易被 shell 二次解析（反引号路径被吃）→ 用文件通道（scp/rsync）整文件传输，不内嵌。
26. 闸门必含词选中文整词（ASR 转写差异要预留）。
27. compose 中间产物固定 /tmp 名 → 跑错旧文件不自知；唯一临时目录（compose_3step.py --tmp-dir 已内置）。
28. PE 参考图 API 键名必须带点嵌套 `images.image_1` + TE 节点接 `vae`（裸键/列表静默失败）。
29. S2V 非 720p 原生 → 口型放大后「香肠嘴」；cfg=1 负向无效 → 约束全写正向。
30. S2V 音频编码器用 chinese-base → 13vs25 维度报错；必须 large_english。
31. H3 单 clip >124 帧 OOM → 长旁白切 S2V，不硬顶。
32. 生成前不查 object_info 节点名 → 节点改名静默失败；提交前预检（talking_segment.py 已内置）。
33. 空白图/小文件假成功 → 回捞时 size 护栏（>100KB）+目检。

34. **H3-TALK（r2va）是参考重生成不是严格首帧**：构图与卡面文字可能被随机重绘（实测一卡文字融化成伪汉字、构图漂成竖排卷轴，另一卡同参却完全保真——逐段运气）。铁律：每段必须做「首帧 vs 源卡」目检比对（自动首尾帧差分只能测漂移不能测错字）；融化段重掷 seed 重试，仍融化→降级「人物左置 talker 帧 + 源卡右半裁片静态 overlay」合成（文字零风险，无面部窗口/无生成式文字）。
35. **批跑循环体内子进程会吃清单 stdin**（两次事故）：`while read` 循环里调 python/ffmpeg 会啃掉重定向文件的后继行（前缀被啃成 _card/05_card、行被跳）。铁律：循环用 `exec 3<清单` + `read <&3`，子进程一律 `</dev/null`。
36. **pkill -f 的模式会匹配命令行自身**：复合命令里 `pkill -f talking_segment.py` 会杀掉承载该字符串的当前 shell（命令静默截断，后续行全部未执行）。铁律：pkill 单独一条命令跑，或用 `pkill -x`/精确 pgrep。

37. **旁白 wav 比段长 → 溢出双声**（"两个人的声音"事故）：装配器 t1 钳位只管字幕窗，adelay 播的是完整 wav——封面旁白 4.9s > 页 4.5s，尾巴灌进下一段与下段旁白同帧播放，听感为两个人声（ASR 转写会把两句叠合成一句"能直接配上门面"）。铁律：装配器必须断言 旁白尾(t0+时长) ≤ 段尾；超了加长页面或缩短文案。ASR 转写出现"两句叠合的合并词"=溢出的指纹。
38. **口型偏移测量必须用互相关法**：阈值 onset 法（唇动差分超阈值 sustained 3 帧）会被呼吸/起势运动污染误测为 0；互相关法（唇动曲线×音频能量包络求最优滞后）实测偏移 0.04-0.46s 逐段不同。工具：measure_sync.py。注入 t0 = 段起点 + 实测 delay。
39. **口播提示词同步句前置**："her lip movements match <Audio 1> exactly" 必须在提示词最前（注意力优先）——talking_segment 恒定追加该句但位置在后；自定义 scene_prompt 时自己再写一遍双保险，并加 "syllable-accurate"。
40. **GPU 多实例并存 = TTS/生成 OOM 假失败**：8188/8189/8190 同时存活（284M+12.3G+5.7G）时 medtts 全灭。铁律：每次 TTS/生成前必查 nvidia-smi，杀掉当前不需要的实例；8190 的自动重启分支会在你以为它已死时把它拉起来。
41. **参考图必须对照权威资产库核验**：按目录命名猜图（xiaoxiao_dz.png）实为抱婴污染图，导致整批人物身份漂移。权威=IP资产库 README 钦定图；用前先目检。
42. **demo 案例选型先过「AI 默认丑配色」关**：荧光粉紫/电紫/高饱撞色（Cherry Blossom）= AI 默认丑配色 = 本 skill 的反面教材；"鲜艳"的合法形态=有品位的鲜活。现成场景不达标时用 skill 本尊 visualize 直出（最强 dogfood）。
43. **PE 封面文字区必须含定位句与结果句**：只罗列测试数/平台数/版本号=用户看不懂 skill 干什么。句式=一眼懂的结果句（红幅标题）+名称+广度定位句（蓝幅"配色 字体 排版 都替你把关"）。⛔版本号上封面。
44. **解说必须念出 skill 名称**，且解说从封面第一秒开始（封面不静音）；名称含英文时旁白预算 +1.5s，页面时长需相应加长（5.5→5.9s）。
45. **PE 场景环境纪律**：⛔蜡烛/烛台/火焰；⛔与内容无关的元素（持卷/道具=易画错，改墙挂/横幅承载文字）；人物双手自然交叠不拿物。
46. **scp 多源拉文件会静默不覆盖本地同名旧文件**（验收看到旧图误判两轮）——拉回验收一律用全新文件名。
47. **装配器重跑会重写 subs.json**——封面段字幕置空（subs[id]=" "防漆字碰撞）必须在每次装配之后打补丁，装配前打会被冲掉。
48. **口播段重生成时序**：TTS 新旁白先生成并校验（transcribe 确认内容），再跑 talking_segment；两者并行抢 GPU+旧旁白开跑=废一段。
49. **飞书交付文件命名禁内部版本号**（v2/v4/v6 用户误以为没更新）——用清晰中文名（如"XX skill 推广视频_完整版_80秒.mp4"）。
50. **demo 场景类型不得与已有图页重复**（仪表盘×2/落地页×2=叙事冗余）；每个案例应展示一种新场景类型。
37. **Blender 相机俯仰角符号**：rotation_euler X=+θ°（如 87.5°）会让相机朝 **+Y（身后）** 看——长廊/走廊沿 -Y 布景时全程拍空墙，且黑场+地板反射极易误诊为灯光问题（本次连调 6 轮灯光全白费）。铁律：布景在 -Y 方向时俯仰一律负值（-87.5°）；黑场先用 Workbench FLAT+RANDOM 模式做几何普查定责，再调灯光。
38. **Principled BSDF 发光通道不可靠**（5.x 实测 Emission Color 链接+Strength=6 渲染仍黑）：灯箱/面板一律用 Emission 着色器直连 Material Output.Surface。
